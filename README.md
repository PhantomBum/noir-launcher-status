# NOIR status

Public announcements, scheduled maintenance, and release notes for NOIR 1.2.0 and newer.

The desktop app reads `status.json` automatically. The owner's GitHub-verified console publishes changes. This repository contains no app credentials or personal library data.

Maintenance only pauses new affected sessions in NOIR. Existing games and playback continue. Offline clients retain the last valid schedule and honor its end time locally.

This feed is not an application binary updater.
